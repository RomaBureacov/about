# Preamble

The rest of this readme is dedicated to explaining why this was developed.
It's intended as a personal monologue to enforce the goals of this project. 

I am currently not really an anybody in the broad world, and so if I wish to
advertise myself, I need some way to share who I am. I could use LinkedIn, but
that has a bad reputation of being basically a Facebook 2.

That being said sites like LinkedIn and Handshake are intended to provide 
valuable information to recruiters and employers in the context of 
business.

But the motivation for this project is two-fold: (1) practice programming, and
(2) make a dedicated page I can pull information from when it comes to business.

# Audience

The intended audience of this webpage is potential employers.

# Purpose

To act as a dedicated source of information to provide in a resume or cover letter,
and to act as a source for additional information if employers become curious.
